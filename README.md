# Eco AI(에코아이) 웹앱 · 숲속탐험대

2024 제71회 경기도교육자료전 실과 분야 3등급 입상작
「자연과 함께 놀며 배우는 생태환경교육 AIDT Eco AI(에코아이)」(박경환·황의준)의 웹앱 버전입니다.

## 실행

* `index.html`을 더블클릭하거나, `실행하기.bat`(Python 필요)으로 로컬 서버(http://localhost:8080)를 켭니다.
* 학교 서버·GitHub Pages·Netlify 등 정적 호스팅에 폴더째 올리면 그대로 동작합니다. (빌드 과정 없음, 서버 코드 없음)
* 기록(XP·배지·메모)은 사용하는 브라우저의 localStorage에만 저장됩니다. `내 여권 → 기록 내보내기/불러오기`로 이동 가능.

## 로그인과 대시보드

| 역할 | 로그인 방법 | 할 수 있는 일 |
|---|---|---|
| 학생 | 학급 코드 + 번호 + 이름 (학급 설정에서 4자리 비밀번호도 켤 수 있음) | 자기 기록(XP·퀘스트·배지)이 학생별로 따로 저장, 선생님 메시지·보너스 XP 받기 |
| 교사 | 아이디 + 비밀번호 (관리자가 발급) | 학급 만들기·명단 관리, 현황표·진도 매트릭스·활동 로그, 학생별 상세(노트·게임·학습 시간), 응원 메시지·보너스 XP, CSV 저장 |
| 관리자 | 이 기기에서 처음 설정한 비밀번호 | 교사 계정 발급·비번 재설정, 전체 학급·학생 검색, 접속 기록, 백업/복원/초기화 |
| 게스트 | 로그인 없이 | 체험만 (교사 대시보드에 안 보임) |

처음 시작 순서: 로그인 화면 → **관리자** 탭에서 기본 비밀번호(`24ecoai`)로 로그인 → 관리자 화면 ‘설정’에서 비밀번호 변경 → 교사 계정 만들기 → 교사로 로그인해 학급 만들기 → 학생에게 **학급 코드** 안내(학급 관리 → 안내 카드 인쇄).

**로컬 모드(기본)**: 모든 기록이 이 기기의 브라우저에 저장됩니다. 학생이 로그인한 기기와 교사가 대시보드를 여는 기기가 **같아야** 기록이 보입니다. (학급 공용 태블릿·교사 PC 한 대 운영에 적합) 다른 기기로 옮기려면 관리자 → 데이터·백업의 백업/복원을 쓰세요.

## Firebase 연동 (선택, 여러 기기에서 기록 모으기)

> ⚠ 학생 쪽(익명 로그인·기록 저장·규칙 차단)은 시험했지만, **교사 가입·관리자 흐름은 아직 실제 프로젝트로 끝까지 시험하지 못했습니다.** 시험 학급으로 먼저 확인하세요. 학생 번호·이름·학습 기록이 외부 서버에 저장되므로 학교·교육청 개인정보 지침과 보호자 동의를 먼저 확인해야 합니다.

교사·관리자는 **이메일 없이** 로그인합니다. (내부적으로 `아이디@teacher.ecoai.app` 가상 이메일로 변환)

1. Firebase 콘솔에서 프로젝트 생성 → Authentication에서 **익명**, **이메일/비밀번호** 사용 설정
2. Firestore 데이터베이스 생성 → 규칙에 `firestore.rules` 내용을 붙여넣고 **게시** (교사 가입 코드 검사가 이 규칙 안에 있음)
3. 웹 앱 등록 후 설정값을 `js/firebase-config.js`의 `window.ECO_FIREBASE`에 입력
4. 앱 로그인 화면 → **관리자** 탭 → ‘관리자 계정 처음 만들기’에서 관리자 비밀번호 설정 (최초 1회, 비밀번호만 사용)
5. 관리자 화면 → **교사** 탭에서 ‘교사 가입 코드’ 저장 (코드는 서버에 저장되며 관리자만 볼 수 있음)
6. 교사는 로그인 화면 → **교사** 탭 → ‘교사 가입하기’에서 이름·아이디·비밀번호·가입 코드 입력
7. 학생 기기는 자동 저장, 교사는 학급 화면의 ‘클라우드에서 기록 가져오기’, 관리자는 학급 탭의 ‘모든 학급·학생 기록 가져오기’로 모읍니다.

교사가 비밀번호를 잊으면 이메일이 없어 재설정할 수 없습니다. 관리자가 ‘등록 해제’한 뒤 새 아이디로 다시 가입하세요.

## 보안 한계 (꼭 읽어 주세요)

* 로컬 모드의 교사·관리자 비밀번호는 해시로 저장되지만 같은 기기를 쓰는 사람은 개발자 도구로 데이터를 볼 수 있습니다. 교사용 PC는 계정 잠금을 사용하세요.
* 학생 로그인은 ‘학급 코드 + 번호 + 이름’이라 같은 반 친구가 알 수 있습니다. 필요하면 학급 설정에서 학생 비밀번호(4자리)를 켜세요.
* 정식 운영(여러 학급·여러 기기)은 서버 인증(Firebase 등)을 권장합니다.

## 내용 추가·수정 방법

* 프로그램(숲·놀·자) 추가: `js/data.js`에 `add({...})`, 퀴즈는 `js/data-quiz.js`의 `Q`에 추가.
* AIplay 도구 추가: `js/data-aiplay.js`의 `AIPLAY` 배열.
* 새 게임: `Eco.addGame('id', {name, emoji, desc, make(){ return 노드 }})` 후 `js/views-arcade.js`의 `ORDER`/분류에 추가, `index.html`에 스크립트 연결.

## 출처·유의

* 원본 콘텐츠(디지털교과서·가이드북·설명서)는 저작자 박경환·황의준의 자료입니다.
* `놀-1~4`(공구 사용법)의 진행 방법, `자-기4 나뭇잎 가면`의 진행 순서, 각 프로그램의 퀴즈·안전 안내는 웹앱용으로 보강한 문장입니다. 영상·활동지를 우선하세요.
* 입상 연구(ONE CHANCE 등)는 구조만 모티브로 삼았고 문장·캐릭터는 새로 만들었습니다.
* 마인크래프트·로블록스 관련 설명은 공개 자료를 요약한 것이며 서비스 정책·링크는 바뀔 수 있습니다.
* 외부 서비스(뤼튼·제미나이·캔바·젭 등)의 이용은 각 서비스의 약관·연령 정책을 따릅니다.
